# PhishShield-XAI

PhishShield is an AI-powered phishing detection and analysis platform. It leverages machine learning to identify and mitigate phishing threats in real-time.

## Project Structure

* **backend**: Spring Boot backend application managing core logic and API.
* **frontend-1**: The user interface.
* **ml-service**: Machine learning microservice for prediction and model hosting.
* **deep-scan-worker**: Worker service for intensive background scanning tasks.
* **contracts**: Smart contracts.
* **docs**: Documentation.
* **infra**: Infrastructure and deployment configurations.
* **model_cache**: Cached ML models for the services.
